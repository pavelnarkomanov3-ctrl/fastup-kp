Как работает динамическое КП через GitHub Pages

Один файл index.html в репозитории заменяет десятки отдельных презентаций и документов.

Шаг 1. Публикация
Создай репозиторий на GitHub

Назови его, например, fastup-kp, загрузи этот файл под именем index.html и включи Settings → Pages → Deploy from branch (main).

Шаг 2. Сборка за 20 секунд
Выбери нишу и сценарий после звонка

Открой свою ссылку, выбери нишу (грузоперевозки, производство, маркетплейсы и т.д.), впиши название компании, имя ЛПР и при необходимости ориентиры по стоимости и рекламному бюджету.

Шаг 3. Отправка клиенту
Скрипт считывает URL-параметры

Кнопка «Скопировать ссылку КП» формирует ссылку с параметром ?view=client&niche=.... У клиента открывается только чистое персональное КП без панели конструктора.

Пример динамической ссылки, которую получает клиент: Скрипт сам меняет все 9 блоков КП
https://username.github.io/fastup-kp/?view=client&niche=logistics&focus=crm_ai&company=ЧП%20«МК%20ЛогТерм»&contact=Екатерина

Настройка КП под ситуацию

Выбери готовый кейс из базы или настрой параметры вручную
