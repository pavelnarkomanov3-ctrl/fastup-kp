# FastUp — Динамический генератор КП (GitHub Pages)

## Структура репозитория
- `index.html` — основной интерфейс конструктора и клиентского КП.
- `data/templates.js` — база ниш (`NICHE_TEMPLATES`) и решений (`FOCUS_SOLUTIONS`).
- `data/leads.js` — сохранённые компании по коротким ID (`LEAD_PRESETS`).

## Быстрый старт на GitHub
1. Загрузите все файлы из этого архива (включая папку `data/`) в корень вашего репозитория (Add file -> Upload files).
2. Включите GitHub Pages: Settings -> Pages -> Branch: `main` -> Save.
3. Используйте короткие ссылки вида `?view=client&id=logterm` или конструктор для новых компаний.
